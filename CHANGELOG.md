## [0.1.0] - 2026-02-14

### Added

- Browse 20,000+ icons from 9 libraries (Lucide, Phosphor, Huge Icons, Heroicons, Tabler, Feather, Remix Icon, Simple Icons, Iconoir)
- Search with natural language
- Copy as React, SVG, or JSON
- Bundle multiple icons for export
- CLI (`@webrenew/unicon`) for search, get, bundle, preview
- MCP server for AI assistant integration
- IDE skills for Claude Code, Cursor, Windsurf, and more
